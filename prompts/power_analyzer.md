# Boss Skill - 权力结构分析模板

## 分析任务

根据收集到的原材料，分析老板的权力结构和行为模式。

---

## 分析维度

### Layer 0：权力红线

**分析要点：**
- 绝对不能触碰的底线
- 老板最讨厌的行为
- 会导致信任崩塌的情况

**提取内容：**
```markdown
## Layer 0：权力红线（不可触碰）

老板绝对不会容忍的：

1. _______________
2. _______________
3. _______________
4. _______________

触发信任崩塌的行为：
- _______________
- _______________
```

---

### Layer 1：身份定位

**分析要点：**
- 职级和位置
- 汇报线
- 在公司的时间
- 上位方式

**提取内容：**
```markdown
## Layer 1：身份定位

- **职级**：P__+ / M__
- **负责业务**：_______________
- **汇报对象**：_______________
- **在公司时间**：____年
- **上位方式**：内部晋升 / 外招 / 收购

身份特征：
- _______________
- _______________
```

---

### Layer 2：决策风格

**分析要点：**
- 决策类型（数据驱动/直觉/民主/独断）
- 信息获取方式
- 决策速度
- 决策考虑因素

**提取内容：**
```markdown

### 决策类型
□ 数据驱动型  □ 直觉型  □ 民主型  □ 独断型

### 信息获取

- 信任的信息源：_______________
- 绕过你的信息渠道：_______________

### 决策特征
- 决策速度：快 / 中 / 慢
- 决策考虑：数据 / 政治 / 直觉 / 综合
- 推翻决策的情况：_______________
```

**分析要点：**
- 如何推进事情（正面/侧面/向上）

```

1. 最需要避免的行为：_______________
2. 最重要的关系维护：_______________
3. 最有效的推进方式：_______________
4. 最佳汇报策略：_______________

汇报注意事项：
- ✅ 应该做：_______________
- ❌ 不应该做：_______________
```

---

## 注意事项

1. **权力是动态的**：权力结构和关系会随时间和事件变化
2. **个体差异**：每个P9+的风格都不同，需要针对性分析
3. **保持中立**：分析权力运作规律，不做道德判断
4. **理解动机**：理解老板的行为动机，而非简单归类
